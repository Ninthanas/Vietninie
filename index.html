🗣️ 越南语六大声调发音图解

声调是越南语的灵魂。点击对应音节即刻聆听发音，掌握高低起伏！

1. Thanh Ngang 平声 · 55

无标号。声音高而平稳，不升不降，类似中文第一声（阴平）。

ma 鬼 / 妖魔
2. Thanh Sắc 锐声 · 35

标号为锐角 (´)。由中音迅速扬升到高音，轻快响亮，类似中文第二声。

má 妈妈 / 脸颊
3. Thanh Huyền 玄声 · 21

标号为钝角 (`)。低沉平缓下落，舒缓柔和，比中文第四声轻很多。

mà 但是 / 却
4. Thanh Hỏi 问声 · 313

标号类似问号无点 (̉)。语调先下沉降至最低，随后微带迟疑地上扬。

mả 坟墓 / 墓地
5. Thanh Ngã 跌声 · 35ˀ

标号为波浪号 (~)。上升至高位时喉咙急剧收紧短暂停顿（喉塞音），富有特色。

mã 马匹 / 密码
6. Thanh Nặng 重声 · 21ˀ

标号为下方圆点 (.)。音质极低沉短促，声音像被利落截断，急促沉稳。

mạ 稻苗 / 秧苗

👥 越南语人称称谓全指南 (Vietnamese Pronouns)

越南语中极少使用像英语 "you/I" 这样冰冷的抽象代词，而是根据彼此年龄长幼与亲疏关系称呼对方。掌握以下核心称谓，越南人会觉得你非常地道且懂礼貌：

Anh 哥哥 / 您 (年长或同辈男士) 用于对稍年长的男性表尊敬与亲近
Chị 姐姐 / 您 (年长或同辈女士) 称呼年轻女店员、女同事非常得体
Em 弟弟 / 妹妹 / 我 (自谦) 对晚辈称呼，或晚辈跟长辈说话时自称
Bạn 你 / 朋友 (平辈之间) 初次认识同龄人、同学之间通用
Cô 姑姑 / 阿姨 / 女老师 称呼长辈女性，或学校女教师
Chú 叔叔 称呼出租车司机大叔、长辈男士
Bác 大伯 / 大妈 (父辈年长者) 称呼年纪比父母大的街头长辈
Ông / Bà 老先生 / 老夫人 对祖父母辈老人家的尊称

🎙️ 越南语真人语音设置说明

Vietninie 优先启用超清在线越南语原声，亦可开启系统离线语音

💡 已自动为你开启：高质量在线越南语真人原声（Google vi-VN 原声流），联网即可流畅发音，声调极其纯正！

如何在 Windows 10/11 安装完全离线的原生越南语语音包？

  1. 按键盘快捷键 Win + I 打开 Windows【系统设置 (Settings)】。
  2. 点击【时间和语言 (Time & Language)】，然后选择左侧或右侧的【语音 (Speech)】。
  3. 在【管理语音 (Manage voices)】区域，点击【添加语音 (Add voices)】。
  4. 在搜索框中输入 “越南语” 或 “Vietnamese”，勾选并点击【安装】。
  5. 安装完成无需重启电脑，Edge 和 Chrome 浏览器即可直接调用微软本地离线超清语音！

苹果设备 (iPhone / iPad / Mac)

苹果 iOS / macOS 系统自带超高音质的越南语 Linh / Siri 语音，点击发音喇叭会自动调用。

安卓手机 (Android)

可在【系统设置】->【语言与输入法】->【文字转语音输出 (TTS)】中确认 Google 语音引擎已勾选越南语。
