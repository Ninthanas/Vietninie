Câu hỏi thường gặp (FAQ)

Bạn chỉ cần bấm nút "Đổi ngôn ngữ / 切换语言" trên thanh menu trên cùng. Toàn bộ giao diện và kho dữ liệu sẽ chuyển sang hướng học tương ứng ngay lập tức.
Khi học Flashcard, bạn đánh giá mức độ nhớ (❌ Chưa nhớ, 😐 Hơi nhớ, 😊 Nhớ, 🔥 Rất nhớ). Hệ thống sẽ lưu vào bộ nhớ trình duyệt và ưu tiên nhắc lại những từ bạn hay quên.
Có! Hệ thống ưu tiên phát file MP3 trong thư mục audio/ và tự động chuyển sang giọng đọc AI bản xứ (Web Speech API zh-CN / vi-VN) trên mọi trình duyệt.
